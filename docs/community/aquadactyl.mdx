Aquadactyl is our self-hosted game server panel, built on Pterodactyl with the
Blueprint framework included. It brings server management, extensions and your
own branding into one panel.

## Make the panel your own

- Install Blueprint themes and addons, with adapters for common legacy extension patterns.
- Set your logo, primary colour, login layout and backgrounds.
- Sign in with passkeys or connect supported OAuth providers.
- Organise servers into personal folders and use per-account language preferences.
- Use the integrated Egg Library and administrator-controlled file trash.

## Get started

The current panel release is [Aquadactyl v1.1-beta.2](https://github.com/Aquadactyl/aquadactyl/releases/tag/v1.1-beta.2),
installed with [Installer v1.1-beta.1](https://github.com/Aquadactyl/Installer/releases/tag/v1.1-beta.1).

[Visit Aquadactyl](https://aquadactyl.uk/) to explore the panel and its features.
The [official installation guide](https://aquadactyl.uk/docs/panel/installing-the-panel)
covers supported hosts, the Git-based installer and deployment. Source and releases
are available on [GitHub](https://github.com/Aquadactyl/aquadactyl).

Aquadactyl is currently in beta. Test your workload and extensions before
upgrading an existing panel, and keep backups of your data and application key.
Legacy extension adapters cover common patterns; individual addons still need
compatibility checks.

For the daemon that runs your game containers, see [Manta](/docs/community/manta).

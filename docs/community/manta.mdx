Manta is the server daemon behind [Aquadactyl](/docs/community/aquadactyl), based on
Pterodactyl Wings. The panel provides the user interface; Manta runs on your nodes
and manages the game containers.

## What Manta handles

- Docker game server installations, power actions and transfers.
- Console connections through the Wings HTTP and WebSocket APIs.
- Server files, backups and SFTP access.
- Linux deployment, with native macOS support for development and small hosts.

Manta retains Wings-compatible API routes and configuration paths. Verify
compatibility with your panel version and test your workload before replacing a
running daemon. Manta is currently in beta.

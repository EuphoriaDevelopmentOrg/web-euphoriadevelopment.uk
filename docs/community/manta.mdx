Manta is the server daemon behind [Aquadactyl](/docs/community/aquadactyl),
maintained by Euphoria Development. The panel provides the user interface;
Manta runs on your nodes and manages the game containers.

## What Manta handles

- Docker game server installations, power actions and transfers.
- Console connections through Manta's HTTP and WebSocket APIs.
- Server files, backups and SFTP access.
- Linux deployment, with native macOS support for development and small hosts.

Manta retains compatible node APIs. Linux configuration now defaults to
`/etc/aquadactyl/config.yml`, with discovery of an existing legacy file when the
new default is absent. Verify
compatibility with your panel version and test your workload before replacing a
running daemon. Manta is currently in beta.

Manta is derived from [Pterodactyl Wings](https://github.com/pterodactyl/wings),
with upstream credits preserved under its MIT license. New installs use the `manta` executable, `manta.service`, the `aquadactyl`
system user and `/var/lib/aquadactyl` data directories. Existing configurations
retain their paths and user IDs until explicitly migrated. See the
[configuration migration guide](https://aquadactyl.uk/docs/manta/installing-manta#migrate-config)
before changing an existing service or Docker mount.

## Get started

The current release is [Manta v1.1-beta.2](https://github.com/Aquadactyl/manta/releases/tag/v1.1-beta.2),
with downloads for Linux and macOS on AMD64 and ARM64. It includes the Manta /
Aquadactyl branding updates and keeps diagnostics local unless an operator
explicitly chooses an upload service.

- [Manta documentation](https://aquadactyl.uk/docs/manta)
- [Installation guide](https://aquadactyl.uk/docs/manta/installing-manta)
- [Source code, platform guides and releases](https://github.com/Aquadactyl/manta)

The official installation guide covers verified release downloads, configuration,
system services, Docker, updates and migration from Wings.
